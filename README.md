# reminder-bot-webapp

Static HTML form (Telegram Mini App) for the [reminder-bot](https://github.com/Tinco0/reminder-bot) Telegram bot.

The bot sends a button that opens this page inside Telegram. The page collects form data and sends it back to the bot via `Telegram.WebApp.sendData`. No backend, no secrets — purely a presentation layer.

Hosted via GitHub Pages.
